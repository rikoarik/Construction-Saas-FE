# Referensi visual superadmin

- `DESIGN.md` adalah acuan visual sekaligus catatan pola revisi UI Superadmin; isi rencana di dalamnya bukan bukti semua fitur sudah diimplementasikan atau scope baru yang otomatis disetujui.
- `assets/superadmin-dashboard-reference.png` adalah gambar referensi visual yang menyertainya. Nama perusahaan, angka, status, grafik, dan kemampuan di dalamnya bersifat ilustratif; jangan dianggap data backend atau fitur yang sudah tersedia.
- Sebelum mengimplementasikan administrasi platform, cocokkan kebutuhan dengan `../../writing-block.md`, kontrak API dan kode aktual. Akses platform tidak otomatis memberikan hak atas konten bisnis tenant. Jangan menambahkan dashboard atau fitur lain hanya karena muncul dalam referensi ini.
